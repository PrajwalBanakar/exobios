# Exobios Frontend

Vue 3 + Vite + Pinia + Tailwind frontend for the Exobios AI-assisted healthcare
platform. See the [repository root README](../README.md) for the full project
description, tech stack, and setup/run/build instructions.

Quick start:

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # production build -> dist/
npm run test    # vitest
```
